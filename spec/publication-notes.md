## Implementation evidence

Profile requirements describe language, runtime, and host contracts. An
implementation must establish the behavior on its actual target and tool inputs.
A specification page alone does not establish platform qualification, package
availability, or permission to redistribute a platform SDK. Consult the exact
release's provenance, inventories, and qualification results.
