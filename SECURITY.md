# Security policy

The initial alpha is experimental. Platform boundaries and resource limits do
not establish the security of arbitrary compiled applications.

Use this repository's GitHub Security reporting channel when available. If
private vulnerability reporting is unavailable, open an issue requesting a
confidential contact without disclosing exploit details or secrets.

Reports should identify the compiler version, OS and architecture, package hash,
minimal reproducer, expected boundary, and observed behavior. Remove credentials
and private application data. Support and qualification claims apply only to the
exact versions and baselines identified by published release notes.
